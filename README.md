# Ciphermind Audit Platform

**AI-powered Cryptography & PQC Readiness Scanner**

## Overview
Ciphermind is a platform to scan repositories for classical & post-quantum cryptography usage, detect crypto misuse, and integrate into CI/CD pipelines for DevSecOps hygiene.

## Modules
- PQC Scanner
- AI Crypto Misuse Detector
- CI/CD Integration

## Quickstart
```bash
git clone https://github.com/sumitgiri87/ciphermind-audit.git
cd ciphermind-audit
# run scanner example
```

- PQC Readiness Score
- Crypto Hygiene Reports
