## Scope of Contributions

We welcome contributions in the following areas:

- Cryptographic algorithm and library registry improvements
- PQC migration mappings and standards references
- Deterministic detection rules and analyzers
- CI/CD integration templates
- Documentation and research references

AI-related contributions must follow the design principles below.

## Contribution Guidelines

- All detection logic must be deterministic and auditable
- Registry changes must include references (NIST, RFCs, standards)
- AI components must be clearly labeled as advisory
- New analyzers should include tests where feasible

## Reporting Issues

Please use GitHub Issues to report:
- Missing algorithms or libraries
- Incorrect PQC status
- False positives / false negatives
- Documentation gaps
